# Data Availability

This release contains derived, submission-safe artifacts associated with the manuscript. It is intended to make the paper's tables, figures, returned item-level listening summaries, and fixed manuscript bundle discoverable and citable.

The release intentionally excludes:

- raw ICASSP/AEC Challenge audio;
- generated enhanced audio clips;
- model checkpoints not cleared for redistribution;
- local caches, temporary files, machine state, and credentials;
- raw individual-rater rows, which were not available to the manuscript.

When a third-party dataset is required to reconstruct an evaluation input, users should obtain the dataset from its official source and use the manifest identifiers and manuscript protocol as reconstruction guidance.

The returned listening material in `artifacts/listening_summaries/` is item-level aggregate evidence, not raw rater-level data.
